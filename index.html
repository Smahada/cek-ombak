Panduan Install Aplikasi di HP

Android (Google Chrome):

1. Buka tautan web ini di Google Chrome HP.

2. Tekan titik tiga (⋮) di kanan atas browser.

3. Pilih "Tambahkan ke Layar Utama" atau "Install Aplikasi".

iPhone / iPad (Safari):

1. Buka tautan web ini di Safari iOS.

2. Tekan tombol Share (Ikon Bagikan) di bagian bawah layar.

3. Geser ke bawah dan pilih "Tambahkan ke Layar Utama" (Add to Home Screen).

Integrasi Google Drive / Sheets

Untuk menghubungkan database web ini secara langsung dengan Google Drive Anda agar bisa diakses di Google Sheet:

  1. Buka Google Drive Anda di https://drive.google.com
  2. Buat file Google Sheets baru bernama "Void Tracker Database".
  3. Klik menu Ekstensi > Apps Script, lalu tempel kode Script Web App penerima data.
  4. Klik Terapkan (Deploy) > Terapkan sebagai Web App (Akses: Siapa Saja / Anyone).
  5. Salin URL Web App yang dihasilkan dan tempelkan di bawah ini.
